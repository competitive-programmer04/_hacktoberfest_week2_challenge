# 🛍️ Listing Writer — Local AI

A privacy-first Etsy/eBay listing generator that runs **entirely on your laptop**. Upload a product photo, pick a voice style, and get a ready-to-paste title, description, tags, and price suggestion — all generated by an open-weight vision model running locally through Ollama.

**No cloud. No API keys. No data leaves your machine.**

---

## Why this exists

Small sellers — Etsy crafters, eBay resellers, flea market flippers — write dozens of listings a week. Generic AI writing tools charge per call and require uploading product photos to a server the seller doesn't control. For sellers listing unreleased inventory or handmade items with proprietary designs, that's a real problem.

This project solves it by keeping **everything local**:

- The model runs on your CPU or GPU via [Ollama](https://ollama.com)
- Your photos never leave your laptop
- Zero marginal cost — generate 1 listing or 1,000, it's free
- Works offline after the initial model download

---

## Features

- **Local inference** — Gemma 3 (4B) vision model runs on your machine
- **Product photo → listing** — upload a JPG/JPEG/PNG, get a full listing
- **Style presets** — casual, professional, vintage reseller, luxury, playful, or write your own
- **Streaming output** — watch the listing appear token by token
- **Honest about uncertainty** — the model writes `[seller to confirm]` instead of inventing measurements it can't see
- **Read aloud** — browser speech synthesis reads the listing back (with a stop button)
- **Download as .txt** — one click to save the listing
- **Works offline** — turn off WiFi, generate another listing

## Requirements

- **Python 3.9+**
- **[Ollama](https://ollama.com/download)** installed and running
- **~4 GB free disk space** for the model
- **8 GB RAM minimum** (16 GB recommended)
- A laptop with a CPU is fine — a GPU speeds it up but isn't required

## Installation

### 1. Install Ollama

Download and install from [ollama.com/download](https://ollama.com/download). After installation, make sure Ollama is running in the background (it starts automatically on Windows and macOS).

Verify it works:

```bash
ollama --version
```

### 2. Clone this repository

```bash
git clone https://github.com/YOUR_USERNAME/listing-writer.git
cd _hacktoberfest_week2_challenge
```

### 3. Create a virtual environment

**Windows (PowerShell):**
```powershell
python -m venv .venv
.\.venv\Scripts\Activate.ps1
```

If PowerShell blocks the activation script, run this once:
```powershell
Set-ExecutionPolicy -ExecutionPolicy RemoteSigned -Scope CurrentUser
```

**macOS / Linux:**
```bash
python3 -m venv .venv
source .myvenv/bin/activate
```

### 4. Install dependencies

```bash
pip install -r requirements.txt
```

### 5. Run the app

```bash
streamlit run app.py
```

Your browser will open at `http://localhost:8501`.

**First run:** The app will detect that the model isn't installed and offer a one-click download (~3.3 GB). After it finishes, everything runs locally.

## Usage

1. **Upload a product photo** — JPG, JPEG, or PNG, max 10 MB
2. **Pick a voice style** — or write your own custom style prompt
3. **Click "✨ Generate listing"** — the model streams the output in real time
4. **Copy, download, or read aloud** the result
5. **Click "🆕 New listing"** to start over with a different product

│  ┌────────────────▼─────────────────────────┐   │
│  │  Ollama (local service)                  │   │
│  │  - gemma3:4b vision model                │   │

└─────────────────────────────────────────────────┘

The app is a thin Streamlit frontend. All heavy lifting happens in Ollama on `localhost`. No external server is contacted at any point during generation.

## Why open-weight models matter here

This project uses **Gemma 3 (4B)**, an open-weight vision model released by Google, running through **Ollama**, an open-source local inference runtime. Both choices are deliberate:

| Concern | How open weights help |
|---|---|
| **Privacy** | Photos never leave the laptop. No API call means no third party ever sees the seller's product. |
| **Cost** | Zero per-listing cost. A closed API would bill per image, which kills the economics for a seller listing 200+ items a month. |
| **Offline** | Works at flea markets, warehouses, and craft fairs with no WiFi. |
| **No lock-in** | Swap `gemma3:4b` for `llama3.2-vision` or `qwen2.5vl` by changing one line. No provider can deprecate the model out from under you. |
| **Customization** | A seller can fine-tune the model on their own past listings to match their voice — impossible with a closed API. |

A closed, cloud-hosted model would defeat the entire purpose of the tool.

## Design notes

### `[seller to confirm]` instead of hallucinated details

The model is instructed not to invent sizes, quantities, materials, or origins. When the photo doesn't reveal a detail the listing needs, it writes `[seller to confirm]` inline. This is more useful than a confident wrong answer — the seller spots the placeholder and fills it in.

### Streaming output

`ollama.chat(..., stream=True)` yields tokens as they're generated. The UI updates a placeholder on each chunk, so the listing appears progressively rather than after a long pause.

### Status feedback during generation

On CPU, generation takes 30–120 seconds. The status box shows `⏳ Reading the photo…` while the model works, so the app doesn't feel frozen.

## Troubleshooting

**"Ollama is not running"**
Start the Ollama background service (Windows/macOS: open the Ollama app; Linux: `sudo systemctl start ollama`), then reload the page.

**Model download is slow**
The `gemma3:4b` model is ~3.3 GB. It's a one-time download. After that, everything runs offline.

**Generation is very slow**
You're likely on CPU inference. Check with `ollama ps` in a terminal — it shows whether the model is running on CPU or GPU. CPU is fine; a GPU just speeds it up.

**"Read aloud" plays no sound**
Some browsers block speech synthesis inside sandboxed iframes. Try Chrome or Edge. Firefox sometimes requires an extra permission.
